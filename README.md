# OSV Insights: Анатомия уязвимостей в Open Source проектах

## Информация о проекте

Данный проект был разработан во время проектной школы AI360.

Этот репозиторий представляет собой копию командного проекта. 
За основу взята ветка `dev` исходного репозитория.

**Оригинальный репозиторий:**
https://github.com/sstar1475/ai360_osv_insights

История коммитов и авторство участников сохранены.

### Мой вклад

В рамках командной работы я занимался:

- **Анализом данных:** изучением и интерпретацией собранной информации.
- **Поиском статистических данных:** выявлением значимых статистических показателей, необходимых для исследования.
- **Сбором информации:** поиском релевантных материалов и источников для проекта.
- **Визуализацией:** представление данных и полезной информации в понятных графиках

## Задача
Проанализировать данные об уязвимостях в open source проектах из базы OSV (Open Source Vulnerabilities), выполнить их очистку и интерпретацию. Подготовить аналитический отчёт с визуализациями, отражающий ключевые закономерности и тренды в области безопасности открытого ПО.

## Что нужно сделать
Собрать данные из OSV API по уязвимостям в нескольких экосистемах (npm, PyPI, Maven, Go и др.)
Очистить данные: обработать пропуски, дубликаты, привести к единому формату

## Провести анализ:
Распределение уязвимостей по экосистемам, типам, годам
Анализ критичности (severity)
Время между обнаружением и исправлением
Наиболее уязвимые пакеты

Создать визуализации: графики, диаграммы, dashboard (8-10 визуализаций)
Подготовить отчёт с выводами и практическими рекомендациями
Презентовать результаты

## Результаты
Очищенный датасет (500-1000 уязвимостей)
Jupyter Notebook с анализом
Письменный отчёт (5-7 страниц)
Визуализации/dashboard
Презентация
GitHub репозиторий
